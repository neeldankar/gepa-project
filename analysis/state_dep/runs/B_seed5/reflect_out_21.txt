4. Structured as a clear question or set of questions that explicitly seek confirmation of the claim's multiple parts.

- Queries should attempt to retrieve missing critical documents/entities not yet confirmed by the notes (e.g., if notes mention some but not all relevant actors or teams).  
- When multiple entities are referenced (e.g., two musicians or two claims about the same person), structure queries to address the relationship between those entities explicitly.  
- Use precise naming (full names, context clues) as available to disambiguate entities and events.

- Break down the claim into constituent factual assertions.  
- Examine notes for what is verified or disproven.  
- Identify gaps or potential contradictions that remain unresolved.  
- Formulate a concise, targeted natural-language query or set of queries that will retrieve documents to conclusively verify each critical part of the claim.  
- Output only the `query` field (and optionally `reasoning` if requested) in the required format.
